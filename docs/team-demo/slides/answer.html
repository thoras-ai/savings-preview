Savings preview

Install and run

# install (one line)

gh release download -R thoras-ai/savings-preview -p install.sh -O - | sh

# run against every cluster they're logged in to

savings-preview --all-contexts

A single binary for macOS and Linux, checksum-verified on install.

Finds Prometheus, Datadog or metrics-server on its own.

Opens a report in the browser in about a minute.

Savings preview · team demo

This is the whole user experience. One line to install, one line to run. It uses the kubectl logins they already have, so there's no setup and no license key. It finds whatever metrics they already collect: almost everyone has Prometheus.
